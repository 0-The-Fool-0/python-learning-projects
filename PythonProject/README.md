# Игра "Точки"

Данное приложение представляет собой реализацию классической игры "Точки" с графическим интерфейсом пользователя на Python и Tkinter.

## Функциональность

1. **Игровая механика**:
   - Выбор размера игрового поля
   - Установка точек с помощью мыши
   - Подсчет очков игроков

2. **Графические возможности**:
   - Настройка цветов игроков
   - Выбор толщины и стиля линий
   - Масштабирование игрового поля
   - Вывод текста и изображений

3. **Интерфейс**:
   - Таблица для отображения счета
   - Полосы прокрутки
   - Слайдеры для настройки параметров
   - Контекстное меню по правому клику
   - Клавиатурные сокращения

## Структура проекта

- `main.py` - Входная точка приложения
- `gui.py` - Класс для графического интерфейса
- `logic.py` - Игровая логика
- `graphics.py` - Дополнительные графические элементы
- `events.py` - Обработка событий
- `widgets.py` - Вспомогательные виджеты
- `tests/` - Юнит-тесты
- `assets/` - Графические ресурсы

## Запуск

```bash
python main.py
```

## Управление

- **Левая кнопка мыши**: Установка точки
- **Правая кнопка мыши**: Контекстное меню
- **C или Delete**: Начать новую игру
- **F1**: Справка

## Требования

- Python 3.6+
- Tkinter
- Pillow (для работы с изображениями)
