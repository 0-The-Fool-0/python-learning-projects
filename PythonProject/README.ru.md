# Игра «Точки» — учебный проект на Tkinter

[English version](README.md)

В этом каталоге находится простой прототип настольной игры «Точки» на поле 10×10 с интерфейсом Tkinter. Игроки ходят по очереди, нажимая на свободные клетки. Кнопка **New game** очищает поле и начинает новую партию с первого игрока.

## Запуск

Требуется Python 3 с Tkinter. Из этого каталога выполните:

```bash
python main.py
```

Тесты логики запускаются так:

```bash
python -m unittest discover -s tests -t .
```

## Текущее состояние

Поле, порядок ходов и проверка допустимости хода реализованы. Метод захвата территории остаётся заглушкой, поэтому захват областей и изменение счёта пока не реализованы. Файлы `graphics.py`, `events.py` и `widgets.py` — отдельные эксперименты, они не используются текущим `main.py`; для `graphics.py` дополнительно нужна библиотека Pillow.
