# Учебные проекты на Python

[English version](README.md)

Коллекция самостоятельных упражнений на Python. Каждый проект оставлен в своём каталоге, чтобы сохранить его исходную структуру и не смешивать разные реализации.

## Проекты

| Каталог | Что реализовано | Технологии |
|---|---|---|
| `PythonProject/` | Настольная игра «Точки»: логика игры отделена от Tkinter-интерфейса; присутствует каталог с тестами. | Python, Tkinter |
| `PythonProject2/` | Визуальная симуляция европейской рулетки. | Python, Pygame |
| `PythonProject4/` | Численный эксперимент с интерполяцией и сплайнами. | Python, NumPy; построение графиков и проверка могут использовать дополнительные библиотеки |
| `PythonProject5/` | Построение кривых Безье алгоритмом де Кастельжо. | Python, NumPy, Matplotlib |
| `PythonYandex1/` | Небольшое вводное упражнение с текстовыми входными и выходными данными. | Python |

Каталог `PythonProject3` не включён: в проверенной копии не было исходных файлов. `PythonProject1` тоже оставлен вне этой коллекции, поскольку его локальное Git-состояние требует отдельного решения.

## Запуск

Единого установщика и общей команды для всех проектов нет. У каждого упражнения собственная точка входа и возможные зависимости. Сначала изучите материалы выбранного каталога.

Примеры предполагаемых точек входа:

```bash
python PythonProject/main.py
python PythonProject2/main.py
python PythonProject4/mms.py
python PythonProject5/1.py
```

Эти команды выведены из структуры файлов; выполнение в этой среде не проверялось.

## Примечания

Это учебный архив, а не единое приложение. Проекты не объединялись, а их версии не объявлялись каноническими. Состав зависимостей, запуск и тестовое покрытие отличаются от каталога к каталогу.
